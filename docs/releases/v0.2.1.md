## Patch changes

- The production image now installs the locked ToxicJoin project metadata after the dependency-cache
  layer, so `importlib.metadata.version("toxicjoin")` is available inside the hardened container.
- `/api/ready.version` is bound to the installed package version and is verified by CI and Phase 6.
- A missing package metadata record now reports `unknown`; it cannot impersonate a historical release
  version.

## Compatibility and claim boundary

- Application and release identity are `0.2.1`; the policy version remains `0.2.0`. They are distinct
  identities, and this patch does not alter policy evidence, benchmarks, disclosure-ledger records,
  model/proof/checker versions, or any ALLOW, REWRITE, or BLOCK decision.
- The canonical disclosure topology remains `SINGLE_NODE`; PostgreSQL is not canonical product behavior.
- This patch does not change the data model, the separate Exact-SHA Live DataHub evidence path, or
  Render resources.
- The [Current Public Demo](https://toxicjoin-public-demo.onrender.com/) remains a Render-hosted,
  temporary synthetic fixture through the real protected execution path. It contains no institutional
  data or credentials and is not the Live DataHub service.
- Render runtime state may reset after sleep or restart and is not a durable audit record.
- Final video publication and Devpost synchronization are not claimed by this release.
